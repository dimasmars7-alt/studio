# PLANNER-002 — надёжное сохранение данных

Статус: реализовано в отдельной ветке `feature/planner-002-reliable-save`.

## Что изменено

- Добавлен явный статус сохранения: локально, синхронизация, сохранено в облаке, ошибка или конфликт.
- Ошибки фоновой синхронизации больше не скрываются: локальная копия остаётся сохранённой, а интерфейс показывает причину.
- Ошибка проверки версии остаётся конфликтом: приложение не затирает облачную версию автоматически.
- IndexedDB повышена до версии 2 и получила хранилище резервных копий.
- Перед изменением данных создаётся внутренняя резервная копия текущего состояния.
- Добавлены тесты для переходов статуса и ошибки облачной синхронизации.

## Ограничения этапа

- Разрешение конфликта по-прежнему выполняется явным действием пользователя через восстановление из облака.
- Сайт, REG.RU deployment и ветка `main` не изменялись.
- Реальные пользовательские данные не использовались.
